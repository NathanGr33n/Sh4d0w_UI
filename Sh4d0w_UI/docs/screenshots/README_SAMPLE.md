## Image Size Guidelines

- **Main screenshots**: 1200x800px or 1400x900px
- **File size**: Keep under 500KB each for fast loading
- **Format**: PNG for best quality
- **Compression**: Use tools like TinyPNG to optimize

## Alt Text Best Practices

Write descriptive alt text that:
- Describes the main elements visible
- Mentions key features being demonstrated
- Is useful for accessibility
- Stays concise (under 150 characters)
